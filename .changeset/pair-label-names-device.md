Let the issuer of a Domovoi client pairing code name the paired device. The issuer's label wins over the name the redeeming device gives itself. A code issued with no label, such as the desktop card's, still names the device by its own name.

Print a word code and browser instructions for web pairing. Show the device label in the command's Devices guidance and explain when an older daemon refuses it.
