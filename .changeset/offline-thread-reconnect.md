A lost daemon is drawn as the Desktop V2 design draws it. The banner sits at the top of the thread
column, names the machine, and offers Retry now as an outline. For a daemon on this machine it says
when it was last heard, which is when this client saw the connection close; over a network, where
a link can die silently, it says no time. Surfaces with no thread column keep the banner across the
window. The thread offers Reconnect to the machine and says why review and move wait for it. The
composer dims, its field and chips go off, and no send leaves it from the field or the prompt
editor while offline. A queued message waits for the connection as well as for its turn, and goes
once the daemon is back. Before the first connection the loading line names the host it dialled
rather than the RPC address, and once the first attempt fails it stops shimmering and says nothing
has been read yet.
