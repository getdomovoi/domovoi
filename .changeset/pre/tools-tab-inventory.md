Skills gains a Tools tab on desktop and web. It lists the tool servers, hooks, rules, env keys, helpers, plugins and skills that the open repository's agent files declare, by agent or by source file, with the repository's trust state. Whether an entry runs when a session starts follows that entry's own held-back flag from the daemon. Files that could not be read and entries the daemon left out are named, so a partial list never reads as the whole. The tab only reads: it grants and takes back nothing.
