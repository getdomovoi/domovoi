The Tools tab can trust the open repository on desktop and web. A repository the daemon holds back shows what does not load and each config file with its counts, and Review and trust opens one review sheet: every entry the repository brings, grouped by file, the configuration digest, and what trust does and does not do. Trust sends the digest shown in the sheet. If the files changed meanwhile, the daemon grants nothing, the sheet says so and reads the files again, and trusting what they hold now is a new decision. A repository whose trusted files changed says so and asks for the review again. Phone and tablet clients, and a watching client, get no trust action.
