Machines draws the Desktop v2 machine card: a status dot, the machine's name, its health, and four facts (TRANSPORT, AGENTS, SESSIONS, LAST HEARD), with Open its N sessions as the one primary action, or See what stalled and a danger border when the machine is unreachable. Agents and sessions come from that machine's own daemon: the home and attached connections, or the reading an admitted machine gives when this client is authorized and each time Machines or Settings opens. A reading that could not be refreshed is dated, and a machine this client holds no client credential for says its agents and sessions are unknown rather than showing another machine's.

Below the cards, Agents and providers lists each machine's installed agents with their state, and Authenticate there names the sign-in command to run on that machine where one is needed. Settings lists the same rows across the fleet under Providers and tokens, in place of this machine's list with its permanently disabled buttons.
