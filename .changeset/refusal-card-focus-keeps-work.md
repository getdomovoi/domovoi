The refusal card takes focus only while the person is still where the refused start left them: the document, the loading line its code loaded behind, or the Domovoi control that opened the start, which now carries a `data-domovoi-opener` mark (the New session buttons, the palette's New session row, the launcher's submit and the fork controls). It waits while focus is still in the closing launcher. Focus anywhere else stays where it is: a text field, an editable region, any unmarked control, another dialog, a frame, any shadow host whether its root is open or closed and whatever its tabindex, and any element inside a shadow root. The card judges the element that holds focus inside open shadow roots, not only their outermost host. Dialog membership now follows the composed tree through assigned slots, so a control slotted into a dialog drawn in a shadow root counts as inside that dialog, both for the control the shell records a start came from and for the card's wait on the dialog the start was made in.
