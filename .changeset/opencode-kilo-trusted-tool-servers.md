OpenCode and Kilo sessions in a trusted repository get the repository's tool servers. When this
machine has trusted the repository and the session worktree's configuration still has the trusted
digest, the daemon adds the `mcp` entries of the OpenCode or Kilo config files it hashed to the
session directory each time the session opens, with a fixed field list, OAuth off, risky
environment keys removed and the embedded server's password blanked. A server that names a
variable or a file, sits in two files, or reads like one of the person's own is held back. The
thread reports that it loaded trusted configuration, so taking trust back stops it, and a stop
disposes the directory's instance, which ends the servers. The tool inventory reports a trusted
repository's OpenCode and Kilo servers that pass as loading.
