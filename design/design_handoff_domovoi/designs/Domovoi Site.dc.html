Switch models mid-project. Where the provider supports native in-session switching, Domovoi uses it. Where it does not, a checkpointed handoff carries the thread, plan, worktree, diff, test results and annotations across. We never claim to move hidden reasoning or provider caches.
PREVIEW AND ANNOTATE
Generated HTML opens in a sandbox, and you can write on it.
plan-preview, design-studio and repo-audit emit ordinary HTML documents. Domovoi renders them byte-for-byte inside an isolated view with no Node access, its own storage partition, permission requests refused, and a separate trust boundary for every document. Click an element to leave a comment on it.
